# XOT ETHAN — Personal Portfolio

A responsive starter portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — page content
- `style.css` — layout and visual styling
- `script.js` — mobile navigation and current year

## Before publishing
1. Replace the starter social links in `index.html` with your own public profile URLs.
2. Update the about section and areas of interest so they accurately describe your experience.
3. Add real projects when you have them.
4. Do not publish private contact details or information you do not want public.

## Deploy with GitHub Pages
In your repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. Your site will be published at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
